# راهنمای قرار دادن سایت در GitHub Pages

این بسته برای مخزن زیر آماده شده است:

`Mohammadbigonah/Mohammadbigonah.github.io`

## روش ساده

1. فایل ZIP را استخراج کنید.
2. همه فایل‌ها و پوشه `assets` را در ریشه مخزن قرار دهید.
3. اگر نسخه قبلی سایت وجود دارد، فایل‌های هم‌نام را Replace کنید.
4. تغییرات را با پیام زیر Commit کنید:

`Upgrade BP-CRERE research portfolio`

5. حدود یک تا سه دقیقه صبر کنید و سپس سایت را باز کنید:

`https://mohammadbigonah.github.io/`

## ساختار صحیح مخزن

```text
index.html
styles.css
script.js
.nojekyll
assets/
  hero-cover.png
  BP-CRERE1.gif
  BP-CRERE2.gif
  BP-CRERE3.gif
  bp-crere-brand.png
  bp-crere-poster.png
```

## فرم پیام

فرم تماس بدون نیاز به سرور طراحی شده است. پس از تکمیل فرم، برنامه ایمیل کاربر با موضوع و متن آماده باز می‌شود و پیام به آدرس زیر ارسال خواهد شد:

`bigonah@stu.hit.edu.cn`

بنابراین هیچ API Key یا سرویس واسطه‌ای لازم نیست و GitHub Pages کاملاً سازگار باقی می‌ماند.

## جایگزینی GIFهای اصلی

اگر GIFهای متحرک اصلی را دارید، فقط سه فایل زیر را با همان نام‌ها جایگزین کنید:

- `assets/BP-CRERE1.gif`
- `assets/BP-CRERE2.gif`
- `assets/BP-CRERE3.gif`
