# راهنمای انتشار نسخه بین‌المللی BP-CRERE

این بسته برای انتشار مستقیم در GitHub Pages آماده شده است و به نصب، سرور یا API Key نیاز ندارد.

## روش انتشار

1. فایل ZIP را استخراج کنید.
2. همه فایل‌ها و پوشه `assets` را در ریشه مخزن `Mohammadbigonah.github.io` قرار دهید.
3. فایل‌های هم‌نام نسخه قبلی را Replace کنید.
4. تغییرات را Commit کنید.
5. پس از یک تا سه دقیقه سایت را در نشانی زیر بررسی کنید:

`https://mohammadbigonah.github.io/`

پیام پیشنهادی Commit:

`Launch international BP-CRERE decision-support site`

## تغییرات اصلی

- پیام اصلی سایت برای سازمان‌های مدیریت بحران، شهرداری‌ها و مالکان زیرساخت‌های حیاتی بازنویسی شده است.
- قابلیت بومی‌سازی، حالت آنلاین/آفلاین و مسیر اجرای پایلوت به‌صورت شفاف نمایش داده می‌شود.
- تصاویر واقعی نرم‌افزار به‌جای تصویرهای تبلیغاتی شلوغ در مرکز طراحی قرار گرفته‌اند.
- منو و مسیرهای ورود برای پژوهشگران، استارتاپ‌ها، شرکای پایلوت و مدیران شهری بازطراحی شده‌اند.
- تصویر واقعی مرکز فرمان، دستیار هوش مصنوعی، خروجی‌های متصل فازها، نمای شهر سه‌بعدی، گزارش شهر و گردش‌کار خودکار در توضیحات مرتبط استفاده شده‌اند.
- برای هر قابلیت اصلی، تصویر، آیکن یا گرافیک اختصاصی در نظر گرفته شده و حرکت‌های ظریف زنده با رعایت تنظیم «کاهش حرکت» کاربر اضافه شده‌اند.
- بخش چارچوب‌های مرجع حذف و با توضیح اختصاصی روش BRB-ER، گرافیک علمی و مرز روشن بین محاسبه و تفسیر جایگزین شده است.
- قابلیت‌های دستیار شهر، Smart Check / Build، گردش‌کار خودکار فازهای ۱ تا ۳ و تولید گزارش تصمیم شهر بر اساس بررسی کد نرم‌افزار توضیح داده شده‌اند.
- بخش‌های «خروجی تصمیم»، «آمادگی کشور»، «روش BRB-ER»، «پایلوت» و «پرسش‌های ذی‌نفعان» در سایت قرار دارند.
- قابلیت‌های فازهای صفر تا پنج بر اساس بررسی فایل اصلی پایتون، به‌صورت مجزا و با خروجی تصمیم هر فاز توضیح داده شده‌اند.
- تصویر و اطلاعات تماس پروفسور Shuang Li و دکتر Mohammad Bigonah در بخش تیم اضافه شده است.
- ادعاهای تجاری کنترل شده‌اند و محدودیت‌های نسخه پژوهشی به‌صورت حرفه‌ای توضیح داده شده‌اند.
- فرم تماس بدون ذخیره اطلاعات، برنامه ایمیل کاربر را با متن آماده باز می‌کند.

## نکته مهم

قبل از استفاده عملیاتی در هر کشور، داده‌ها، فرضیات مهندسی، اصطلاحات، ساختار تصمیم‌گیری و الزامات امنیتی باید با سازمان مسئول همان کشور بررسی و تأیید شوند.
